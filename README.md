# cv

Ce dépôt est une copie du modèle LaTeX **autoCV** (licence MIT), utilisée pour produire mon CV en
PDF. Le code du modèle n'est pas de moi, je ne le présente donc pas comme un projet personnel.

Le fichier `cv.tex` contient mon CV. Une GitHub Action compile le fichier LaTeX et publie le PDF à
chaque modification.

Le contenu du modèle d'origine et ses instructions sont conservés ci-dessous pour mémoire. Le même
modèle est aussi dans le dépôt `cvd`.
